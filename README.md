# جيو الرافدين — منصة الخدمات والمصادر الجغرافية

واجهة عربية متجاوبة لمنصة الخدمات الجغرافية والاستشعار عن بُعد، تشمل:

- عرض الخدمات ومصادر البيانات.
- مكتبة بحثية قابلة للبحث والتصفية تضم مصادر رسمية موثقة، مع الدقة والتغطية والترخيص والاقتباس المقترح.
- ملف بحث محلي يجمع حتى 12 مصدراً، ويصدر البيانات الوصفية إلى CSV والمراجع إلى TXT، وينشئ رابط مشاركة وطلب تجهيز موحداً دون إرسال بيانات شخصية تلقائياً.
- مخطط دراسة جغرافية من أربع مراحل ينظّم السؤال والنطاق والبيانات والمنهج والمخرجات، ويولد موجزاً قابلاً للطباعة ويربط المصادر المقترحة بملف البحث ونموذج الخدمة.
- مركز أدلة وقوالب للباحث يضم إرشادات تطبيقية قابلة للبحث والحفظ محلياً، مع قوالب CSV وTXT لتوثيق البيانات والمعالجة والمرئيات والخريطة والمنهجية.
- أداة تدقيق جودة الدراسة عبر 25 معياراً في خمسة محاور، مع حفظ محلي ودرجة جاهزية وتوصيات مرتبة وتقرير TXT قابل للطباعة.
- ربط كل مورد بنموذج طلب تجهيز البيانات، مع لوحة إدارة محتوى محمية بالمصادقة الثنائية.
- نموذج طلب خدمة مع تحقق من الحقول.
- تسجيل دخول آمن عبر رابط بريد إلكتروني دون كلمة مرور.
- قاعدة بيانات محمية بسياسات وصول على مستوى الصفوف.
- تخزين خاص للملفات ولوحة للعميل والمدير.
- خريطة تفاعلية لمحافظات العراق لتحديد منطقة الدراسة.
- متابعة إدارية للسعر ونسبة الإنجاز والتسليم ورسالة العميل.
- دورة عرض سعر آمنة تتيح للمدير إرسال نطاق وسعر وموعد، وللعميل قبول العرض أو رفضه مع سجل قرار مؤرخ.
- محادثة محفوظة داخل كل طلب مع إشعارات فورية داخل الحساب وحدّ إرسال يمنع الإساءة.
- تسليم آمن للإصدارات النهائية في حاوية خاصة، مع روابط تنزيل مؤقتة وسجل واضح لكل نسخة.
- رفع ملفات GeoJSON وGeoPackage وملفات الشيب فايل المضغوطة بصيغة ZIP ضمن حدود آمنة.
- سياسة خصوصية واحتفاظ لمدة 90 يوماً، وسجل تدقيق لإجراءات المدير.
- مسار مصادقة ثنائية للمدير وتجهيز Cloudflare Turnstile.

## التشغيل

بعد إكمال [`SETUP.md`](SETUP.md)، انقر مرتين على:

`Start-GeoRafidain.cmd`

ستفتح المنصة على `http://127.0.0.1:8765`. أبقِ نافذة التشغيل مفتوحة أثناء الاستخدام.

يمكن فتح `index.html` لمعاينة التصميم فقط، لكن تسجيل الدخول والطلبات محجوبان عبر `file://` لأسباب أمنية.

## حالة النسخة الحالية

المشروع مربوط بـ Supabase، ويحتوي ترحيلات الحماية والعروض وملفات GIS والتواصل والتسليم ومكتبة المصادر البحثية، ويستخدم نسخة محلية ثابتة من `supabase-js 2.108.2`. لا تضف أي مفتاح Secret أو Service Role إلى الواجهة.

قبل النشر العام يلزم نطاق HTTPS، وتفعيل Turnstile/SMTP، ونشر مهمة الحذف الموجودة في `RETENTION.md`، ثم اختبار بحساب عميل منفصل.
